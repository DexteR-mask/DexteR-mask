I am a backend and distributed systems engineer specializing in high-concurrency transaction lifecycles, Go microservices, and private local LLM inference pipelines. I focus on deterministic state machines, fault tolerance, and developer platforms.

- ⚙️ **Core Engineering:** Low-latency backend architectures, distributed transaction safety, and developer tools.
- 💳 **Payment Systems:** Engineered end-to-end payment gateway integrations in Go for Stripe and Braintree (PayPal), including idempotent lifecycles, automated refunds, and robust webhook verification.
- 🧠 **Local AI Systems:** Architecting and maintaining private GPU-accelerated local inference clusters (`vLLM`, `llama.cpp`) on bare-metal hardware.
- ⚡ **Engineering Principles:** Make failure states predictable, eliminate unnecessary dependencies, and optimize the critical execution path.
